\# MESH — AI-Powered Interdisciplinary Collaboration Platform



MESH is a platform designed to connect university students across different departments and help them build interdisciplinary project teams.



\## 🎯 Problem Statement



University students often struggle to find collaborators from other departments who have the complementary skills needed to turn their project ideas into reality.



\## 💡 Our Solution



MESH helps students discover collaborators based on their skills, interests, experience, and project requirements.



\## ✨ Key Features



\- \*\*Student Profiles:\*\* Showcase skills, interests, and experience.

\- \*\*Project Ideas:\*\* Create and explore interdisciplinary project opportunities.

\- \*\*AI-Assisted Matching:\*\* Identify complementary skills and potential teammates.

\- \*\*Join Requests:\*\* Request to join projects and manage incoming requests.

\- \*\*Team Collaboration:\*\* Bring students from different departments together.

\- \*\*Project Closure Workflow:\*\* Support project completion requests and team decisions.



\## 🛠️ Technology Stack



\- \*\*Frontend:\*\* React, Vite, CSS

\- \*\*Backend:\*\* Java, Spring Boot

\- \*\*AI Service:\*\* Python

\- \*\*Build Tools:\*\* npm, Maven
